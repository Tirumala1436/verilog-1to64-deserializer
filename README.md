# 1-to-64 Deserializer (Verilog)

## Overview
This project implements a synthesizable 1-to-64 deserializer.

## Features
- Full-rate serial clock sampling
- 64-bit parallel output
- Valid signal generation
- Self-checking testbench

## Architecture
- 64-bit shift register
- 6-bit counter (2^6 = 64)
- Parallel word output every 64 serial clocks
